# Rust 与 Python 热点迭代本地验收 · 2026-11-18

R0–R7 已在 macOS ARM64 完成本地验收。基线为 v0.6.24（`8757b728`），候选保留包版本号，私有扩展协议从 45 升至 46。用户选择本地验收，平台覆盖为 macOS ARM64。

## 实施与取舍

| 轮次 | 落地与验证 |
| --- | --- |
| R0 | 冻结 32 份 PDF、24 份非 PDF 的字节、解析选项、HTML 来源、运行时及扩展指纹。独立的基线副本保留原协议和二进制。 |

| R7 | 全量回放、真实文件导出、宿主回放、源码回归和同一 wheel 的两个独立安装环境均已验证，逐样本数据见下表。 |

## 解析、导出和安装

- 31 份成功 PDF 和 24 份非 PDF 的 ModelJson、MiddleJson、素材名称及字节摘要、diagnostics 在每次回放中一致。`small_ocr.pdf` 在两个版本均按预期抛出同类型、同消息的 OCR 拒绝。
- 四份焦点 PDF、两本 EPUB、真实 XLSX 和 ODS 实际写出 Markdown 与 HTML，主文件与素材逐字节一致。四份 PDF 的 25 页版面标框经 Poppler 96 DPI 渲染，尺寸及所有 RGB 像素一致。审阅页包括英文论文第 9 页、中文论文第 3 页、财报及研究报告各第 2 页，覆盖跨栏正文、表格、注释与图表。两本 EPUB 的 HTML 分别含 34、182 个链接，XLSX、ODS 的表格及媒体均参与比较。
- MinerU 使用同一本地工作树（HEAD `1f038d16`，含已有的 `hybrid.py` 改动，其摘要已记录），对同一冻结布局运行 31 份 PDF 的 medium 和 high 两档原生表格与文字回填，共 62 组。表格采纳、回退模型输入、输出模型、几何调用和固定 OCR 回调记录均一致。
- Python 3.14.4 全量测试 14,688 项通过，1 项因本机缺少 TeX Live 工具跳过。Rust 工作区 54 项通过，`cargo fmt --check`、Clippy 严格模式和源码 Ruff 检查通过。
- 从干净源码副本构建 `docvortex-0.6.24-cp311-abi3-macosx_14_0_arm64.whl`。CPython 3.11.15、3.14.4 各在独立环境通过 ABI、两份真实 PDF、非 PDF 解析与导出及 2,369 项安装回归。两环境的两份 PDF 完整安装输出也逐份一致。wheel SHA-256 为 `5a773d146424ce4b8212f58a6b19da2545a2bb781110a25ec0560e82fffc7e67`。
