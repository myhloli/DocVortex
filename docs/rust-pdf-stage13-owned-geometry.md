# PDF 原生内核阶段 13：自有文档几何与样式校准

## 实现范围

实现检查点 `7481460582863b2370109291183c75ab54f98bc5`，私有协议 18。继续单人串行推进，性能基线仍为 DocVortex `3eef2d1` / MinerU `cabe6e34`，RSS 预算仍为原始基线的 130%。

本批把字符几何准备、锚点筛选、run 统计、跨页样式判断、全文字号校准与来源框恢复接入同一份 Rust 自有文档数据。字体/Unicode 编码仍使用 Python 的既有语义；纯 Rust 数值计算释放 GIL，不新增线程池，不访问 PDFium 指针。

- 仅样式风险的文档直接产生计划字段，不构造 `_CharSample`。
- 需要 X/Y 规则的文档先在 Rust 内完成前置计算，最后只物化一次字符和 run；不再把刚物化的字符逐字段读回 Rust。
- 跨页样式成立时先恢复来源框，再计算最终 run 统计；避免恢复前后重复计算和导出。首见并列字体、重复来源行、run 集合顺序和来源恢复顺序保持原行为。
- 接受原生文档后，在布局对象物化前释放已复制的 loose 侧表；拒绝输入时保持侧表完整以便走参考路径。自有文档单次消费，结束后再次追加或结束明确报错。
- 参数或自定义规则不支持时明确走参考路径；原生计算与物化错误直接传播。字体自定义转换在试探阶段不执行，避免回退后重复调用。

X/Y 修复及部分行级几何仍在 Python，PDFium 文档所有权、矢量快照、完整表格/布局内核和最终后端退出尚未完成，不能将本批称为 P4/P5 完成。

## 试测与问题定位

早期仅移动样式计算、增加数据桥接的候选没有稳定收益，部分热点还出现退化；所有 `candidate-stage13*` 副本和试测记录保留。独立阶段/GC 诊断未发现 GC 增长能解释退化，不能据此宣称调整回收策略带来了速度收益。

实际定位到两处阻断：布局文档存在全局样式异常时尚未走通原生恢复；真实字符来源框使用自有 `Bbox`，兼容恢复入口却只接受普通序列，导致部分计算后再次走参考流程。本批补齐了两处支持，并添加真实 `Bbox`、完整记录、四方向旋转、自定义转换次数、拒绝不产生部分恢复、单次消费等测试。

最终 `candidate-stage13g` 相对协议 17 的三样本试测中，demo1 降低 4.84%，中文论文2 降低 4.19%，49.- 降低 1.70%；完整输出一致。这里只用于选方案，不代替全量正式验收。

## 正式性能

三条链路顺序测量。每份文档预热一次、测量五次，逐文档交替版本；超过 5% 的退化反序复测。首次中位数保留在总和，进程树 RSS 独立采样，构建、测试、真实模型录制与诊断不和计时混跑。

| 链路 | 样本数 | 基线中位数之和 | 候选中位数之和 | 耗时降幅 | 最大 RSS 比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 公开 `parse()` | 32 | 21.898346 s | 17.259372 s | 21.18% | 108.68% |
| MinerU Flash 文本 | 31 | 23.649920 s | 17.687530 s | 25.21% | 108.39% |
| MinerU 实际 medium 共享路径 | 32 | 24.801042 s | 15.072112 s | 39.23% | 93.18% |

三条入口全部输出一致，首次测量即无超过 5% 的单样本退化，无 RSS 超限，三个正式驱动均退出 0。共享入口冻结模型计算，回放交付开销仍计入；扫描 OCR 样本不计入 Flash 文本指标。

上述结果是相对原始冻结基线的累计收益，不能将其全部归因于本批。与协议 17 的增量收益仅采用前述同场三样本试测；不同批次共享入口总和的波动不能作为本批增益或退化的独立证据。公开与 Flash 距 2 倍目标仍分别需要在当前耗时上降低约 36.56% 和 33.15%，共享入口约 17.72%。

本批未重新验收完整冷启动和长期连续处理；已有协议 16 的对应记录保持原版本标识，不重标为协议 18 成绩。最终 2 倍目标仍需三条链路分别达到 50% 降幅，并补齐长期稳定性及发布验收。
