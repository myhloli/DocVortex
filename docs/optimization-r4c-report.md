# R4C OFD 原始字形边界复用验收报告

日期：2026-10-25。以R4B最终源码为基线，DocVortex保持0.6.1，Rust内核及协议40不变。

**R4C本机验收通过。** 复用成功原始字形边界后，两份嵌入字体重复压力的公开热耗时中位数之和下降46.70%，普通真实OFD约下降12.64%；54份累计输入完整输出一致。13447项测试、59份导出输入及同一wheel在Python3.11/3.14的安装验证通过。

16份真实综合输入合计约-0.36%，接近持平。全新字形主测约+8.07%/1.79ms，反序复测约+3.58%/0.68ms，未命中成本完整保留；不把重复压力收益推广为所有真实文档收益。

## 1. 定位和实现范围

在冻结R4B源码上重新profiling，嵌入字体短/长压力样本的`glyph_bbox()`累计时间约占profile总时间85%/90%。原实现每次调用都创建BoundsPen并描边，同一字形重复出现时仍重新计算原始边界。

生产修改仅在`src/docvortex/analyzers/native/ofd/text.py`：

- `_LoadedFont`新增可选原始边界缓存，仅由本解析器成功加载的只读字体启用，按字形名称存字体单位下的四坐标tuple。
- 每字体至多1024项；满后停止新增，已有条目继续命中，不循环淘汰。缓存随本次字体解析器关闭释放，不跨文档共享。
- 字号、水平缩放、advance表和advance hint仍逐次参与原计算。最终BBox、缩放失败的回退框及调用参数不入缓存。
- 空路径和描边异常不缓存，保持每次重试；替换BoundsPen、外部字体替身或默认手动构造的LoadedFont保留逐次描边。
- 资源读取、字体解析失败缓存、cmap映射、字形ID优先级、Delta、裁剪、文字展开预算和原生几何分流均保持原行为。

该缓存依赖解析器内部加载的FontTools字体在本次解析中只读；不对外部修改内部字体表提供缓存失效协议。每字体容量有界，不称作整个解析流程常数内存。
