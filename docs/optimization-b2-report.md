## 1. 本批结果

在已经核对字符度量保持不变的页面阶段内，共享 `has_inflated_native_cjk_metrics()` 的判断结果。缓存同时覆盖 True 和 False，不改变字符筛选、二十锚点门槛、三个中位数或任何判定阈值。

- `nougat.pdf`：完整统计从 **206 次降至 49 次**；正式 parse 中位耗时降低约 **6.1%**。
- 61 页异常中文度量样本：完整统计从 **1272 次降至 183 次**；正式 parse 中位耗时降低约 **9.7%**。
- 聚焦测试：**2019 passed**，其中包含新增的 25 项阶段/视图/生命周期回归。
- 38 份输入合同一致：**37 份、443 页**完整原生解析输出相同；另 1 份、8 页扫描 PDF 保持相同的 `pdf_ocr_unsupported` 拒绝。
- 五个正式性能样本均无持续回退；最大 RSS 比率约 **1.0299**，未超过 5% 门槛。
- 六个代表原页的前后标框像素相同；三组 HTML 和 ORIGINAL/REFLOW PDF 导出的字节及诊断相同，人工检查了 **13 页导出结果**。

生产修改只涉及 `pipeline.py` 与 `table_filled_grid.py`。没有修改 Rust、公开协议、版本、布局规则或前两批实现。

## 2. 调用链、视图与失效边界

| 消费者 | 输入视图 | 处理方式 |
| --- | --- | --- |
| 填色表格 `_detect_tiled_fill_table_candidates` | `source.chars` | 同阶段同一列表共享判断 |
| 表题绑定 `_bind_short_native_grid_captions` | `source.chars` | 与表格和图形消费者共享 |
| 图形检测 `_detect_native_diagram_components`、`_detect_stacked_column_graphics` | `source.chars` | 同阶段重复调用不再完整重扫 |
| `source` / `analysis_source` / `table_analysis_source` | `replace()` 只改变行或绘图线时，仍持有同一个字符列表 | 共享精确列表视图，不按 source 对象或行集合误拆 |
| `restore_native_cjk_bands` | 从剩余行重新组合的字符列表 | 独立计算，不借用整页或其他子集的结论 |

复用只在两个入口启用：

1. `_collect_document_sources()` 每页的 `_detect_strong_graphic_bboxes()` 调用范围。噪声过滤在作用域外执行，可以替换 `source.chars`。
2. `_prepare_page_source()` 的单次调用。当前几何修复修改行对象；表格校准构造字符副本，原始字符度量不被原地改写。重新组合的字符列表作为不同视图处理。

独立调用 `has_inflated_native_cjk_metrics()` 时，作用域默认不存在，每次都读取当前输入；非列表迭代器也不缓存。原始计算移入 `_compute_inflated_native_cjk_metrics()`，计算内容保持原样。

阶段状态使用 ContextVar，进入时创建、退出或异常时恢复。索引虽然使用 `id(chars)`，但条目同时持有真实列表并以 `is` 核对身份，防止对象回收后 ID 被复用。引用不会跨页长期保留。嵌套阶段返回时清除外层已有判断，避免重入期间修复共享字符后恢复过期结果。

`_native_graphic_em` 等其他统计使用的过滤条件并不完全相同，本批没有将这些计算强行合并。复用范围以原判断的输入与阶段契约为准。

三个样本分别用参考与候选独立解析，保存完整输出。候选额外核对同一阶段重复查询时的字符文字、bbox 和 tight_bbox，共通过 **1305 次**重复视图检查；解析结束后阶段状态均恢复为空。

计数审计包含额外的不可变性检查，不用于性能结论。下节计时使用未包装的实际入口，且校验了审计输出与正式运行输出的摘要一致。
