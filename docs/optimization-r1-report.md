日期：2026-10-25。R1 在 N0–N6 已验收候选上迁移电子表格区域计算，当前版本保持0.6.1，私有原生协议由36升至37。

## 1. 实现范围

Rust 核心位于 `rust/docvortex-core/src/spreadsheet_regions.rs`，PyO3边界位于 `rust/docvortex-python/src/spreadsheet_regions.rs`。

- 每个工作表一次传入有序起点、连接点、连接矩形、语义原点和合并跨度。Rust 连续完成三档 gap 的 BFS、评分和稳定候选选择，运算期间不逐格回调 Python。
- 保留右/左/下/上的最近邻停止、原起点顺序、无条件起点、全局 visited 只跳过后续起点，以及0.15评分邻域和1→0→2偏好。
- 语义评分针对整个区域 bbox，合并跨度使用矩形并集；稀疏区间统计空行列及覆盖，不按巨大 bbox 面积分配布尔矩阵。整数评分范围超过2^53时显式拒绝不精确转换。
- 严格语义子集筛选使用长度索引，只比较更大集合，等长和相等集合不进入包含比较，输出保留原索引顺序。
- PyO3接收自有整数快照，在纯计算阶段释放GIL，返回时恢复既有 `ConnectedRegion`/不可变成员集合。输入临时快照在物化/裁剪前释放。

XLS/XLSX 的评分语义与单元格物化后的语义不同，因此仍物化全部获选区域，再按真实物化语义批量筛选。ODS 可在原语义点集上取得保留索引，再裁剪。

DISPIMG 的失败/矢量回退会产生逐次诊断，保留原候选顺序及访问序；连接发现仍可批量进入 Rust。自定义发现/语义钩子、动态候选/偏好/margin/评分函数，以及 ODS 手工浮点或超i64跨度，保留原回调行为。

公开 API、ModelJson/MiddleJson 类型、素材、表格分割规则及分页合同不变。源码使用需要匹配协议37的扩展，协议36被当前加载器明确拒绝。
