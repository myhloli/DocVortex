# B3 验收报告：页内共享 Form 裁剪范围

日期：2026-10-24。范围与门禁沿用 [分批优化计划](optimization-plan-2026-10-23.md)，本批对照为已验收 B2 → B3。

## 1. 结果

B3 已完成本机验收。一次 `_extract_native_page()` 内，Form 边界提取和结构提取共享相同根对象、页框和旋转下的裁剪范围，包括 `None`。原裁剪计算与对象树遍历不变。

- 三份真实 Form 样本的完整 extent 计算和叶子访问均减半；`nougat` **30→15** 次、研究报告 **16→8** 次、EMNLP 论文 **36→18** 次。
- 五个正式性能样本的热运行中位耗时降低约 **1.6%–3.6%**；逐样本中位耗时之和降低 **2.32%**。
- **523 项测试通过**，包含新增的 31 项缓存边界与生命周期回归。
- **37 份、443 页**完整解析输出一致；另 1 份、8 页扫描 PDF 保持相同拒绝合同。
- 六个原页的前后标框像素相同；三组 HTML、全部旁文件及两种 PDF 导出相同，人工检查了 **16 页导出结果**。

生产修改仅涉及 `document/pdf/_document.py`、`native_objects.py`、`form_structure.py`；没有修改 Rust、公开协议、版本或版面规则。

## 2. 调用链和生命周期

`PDFDocument._extract_native_page()` 在现有 `_open_page()` 锁与页面作用域内创建局部字典，依次传给 `_extract_page_form_bboxes()` 和 `extract_form_structure()`。两个消费者通过 `_shared_clipped_form_extent()` 查询原有 `_clipped_form_extent()`。

| 边界 | 实现与验证 |
| --- | --- |
| 页内对象身份 | 键包含根 Form 的数值地址、完整页框和旋转；字典只属于当前页面的一次提取 |
| 重复资源调用 | 同一 XObject 的不同调用实例使用各自的 PDFium 对象地址，独立计算矩阵下的范围 |
| 参数不同 | 不合并不同页框或旋转；包括调用链中原始旋转与规范旋转不同时的情形 |
| 无裁剪与空范围 | 使用键是否存在判断命中；`None` 和零面积框均可缓存 |
| 异常隔离 | 仅在计算成功返回后写入；异常不缓存。边界提取仍隔离单对象错误，结构提取仍按原行为传播或重试 |
| 释放 | `finally` 在两个消费者退出时清空字典，早于文字提取及页面关闭；成功与异常路径均有检查 |
| 独立调用 | 两个提取函数的可选关键字参数默认 `None`，独立查询每次读取当前对象，不要求提供内部缓存 |
| 借用句柄 | 缓存只保存数值键和不可变 bbox/None；快照不持有缓存、裸句柄或借用对象 |

根对象矩阵、累积 clip、可见叶子计算、遍历顺序及 `DRAWING_FORM_MAX_DEPTH = 15` 保持原实现。只共享结果，不合并两条完整对象树遍历，也不扩大为文档级或全局缓存。

## 3. 真实调用次数与 Form 几何

在计时之外，通过公开 `parse()` 分别审计参考与候选。每页临时对象地址转换为页内序号后丢弃；保存完整 `form_bboxes`、`form_infos`、ModelJson、MiddleJson、素材摘要和诊断。

| 样本 | 页数 | 完整 extent 计算：参考 → 候选 | 叶子访问：参考 → 候选 |
| --- | ---: | ---: | ---: |
| `nougat.pdf` | 17 | 30 → 15 | 24,534 → 12,267 |
| `research-report.pdf` | 5 | 16 → 8 | 8,314 → 4,157 |
| `2022.emnlp-main.614.pdf` | 18 | 36 → 18 | 9,116 → 4,558 |

所有候选页面的相同根对象/参数均恰好计算一次；Form 几何和完整输出全部相同。nougat 原有调用中，可见范围分支 16 次、无裁剪 `None` 分支 14 次，候选分别为 8、7 次，真实文档覆盖了两类结果复用。

审计包装与正式性能计时分开，审计中的局部耗时仅用于诊断。证据为 `form-audit/`、`form-audit-summary.json` 和对应命令、日志。
