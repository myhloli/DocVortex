# 非 PDF Flash 首轮优化验收报告

日期：2026-10-25。基线为 `1e7bc45aa7feb50bf305be46dbefe718f91bbfee`，版本保持 0.6.1，Rust 私有协议保持 36。对应 [分批计划](optimization-plan-2026-10-25.md) 的 N0–N6。

首轮验收通过。五项生产优化减少 ODF 网格扫描、XLS 尾部复制、XLSX 重复投影、DOCX 重复读取和 RTF 全文扫描。14 份真实输入的公开解析热耗时中位数之和下降 **4.33%**，7 份压力输入下降 **38.63%**。本轮没有实施新的 Rust 计算核；R1 电子表格区域发现仍是下一阶段。

## 1. 改动与边界

| 批次 | 实际变化 | 保留的合同 |
| --- | --- | --- |
| N0 | 既有配对基准支持冻结多格式 manifest；后缀和 HTML 来源纳入计时/RSS 身份；PDF profile 仅包装高层编排，保持 owned style 快路 | 完整输出四分量、实际导入来源、扩展摘要、跨轮稳定性、独立进程 RSS |
| N1 | ODF 仅在独占构建期增量维护宽度；裁剪后返回普通 `TableGrid` | 分配前预算、重复行列和合并格、返回后任意修改 `rows` 的实时宽度 |
| N2 | BIFF 全零尾部检查改为共享 `memoryview`，消除逐记录的剩余流字节复制 | EOF、零填充、负起点、截断告警、记录预算；BOF 恢复扫描保留 |
| N3 | XLSX 转换内复用相同样式的投影，并返回独立字典；成功 DISPIMG 位图/公式复用 | 仅当前工作簿、reset/finally 清理、公式预算；失败、缺失和矢量降级路径仍保留原调用与告警 |
| N4 | 正文和表格共用一次 OOXML `Document()`；无正文顶层表格时跳过 Mammoth；表格对齐复用未修改候选的签名 | 表格匹配顺序、公式注入、完整上下文回退、特殊字符、独立预解析及实例失败后复用 |
| N5 | 单次 RTF prelude 建立五类 destination 索引，全文扫描由 5 次降至 1 次 | 组闭合顺序、首个匹配、bin/Unicode/代码页、独立 lexer 预算及错误优先序 |

N2 改善的是复制成本；构造性的连续零头记录仍可能重复执行尾部扫描，不宣称全部 BIFF 扫描已经线性化。N3 缓存限于 XLSX，没有把旧 XLS 的样式投影一起改写。N5 没有跨元数据和正文共享可变解析状态。

N4 可以减少被跳过预解析路径的调试信息或图片告警。公开结构化 diagnostics 已完整比较；关闭 Loguru 的性能基准不证明逐条日志文本完全一致。

## 2. 基线与测量方法

证据根目录为 `/Users/myhloli/Documents/Codex/docvortex-nonpdf-optimization-20261025`，下文路径均相对此目录。

- `reference-source` 冻结共同基线；`N1-source` 至 `N5-source` 按批叠加；`candidate-source` 为最终生产候选。各批补丁和范围在 `N1.patch` 至 `N5.patch`、`batches.json`。
- `corpus/manifest-complete.json` 固定 23 份字节输入：14 份真实样本、CSV/TSV 两份小夹具、7 份压力输入，共覆盖 16 种非 PDF 格式。
- 压力输入包含 ODS 600×10、XLSX 1000×10、无表 DOCX 1000 段、DOCX 20 张表共1000格、RTF 2000段、CSV 10000×10，以及有4万条 BLANK 记录的 XLS 容器。
- 正式计时为无额外探针的公开 `parse(..., keep_model_json=True)`，显式后缀及 HTML 来源固定；序列化和摘要计算放在计时之外。
- 累计及每批相邻版本均执行五轮 AB/BA 交替运行。每份输入先预热，RSS 在另一独立进程测量。正式测量期间没有并行构建、测试或导出负载。
- 本文汇总使用“逐文档五轮热耗时中位数之和”。基准工具另保留“整轮总耗时的中位数”，两种统计口径不混用。

## 4. 首次调用和 RSS 复测

首次调用检查使用八份真实 DOCX/XLSX/XLS/RTF/ODT/ODS/ODP/HTML，每版三轮独立解释器、全新空 `PYTHONPYCACHEPREFIX`。计时包含 parse 内惰性导入及相应字节码编译，排除解释器启动、预先包/身份导入和读盘；没有清空操作系统文件缓存。完整输出与正式累计首轮一致。

HTML 对照初测比率 1.05045；反序五轮复测为 **0.99192**，未出现持续退化。其余首次调用中位数比率均低于1.05。原始记录位于 `first-parse-01` 和 `first-parse-html-recheck-01`。

XLSX 压力输入在50 ms线程采样中出现两档峰值：候选约112–125 MB，取决于是否采到解析末段；累计初测比率1.052，局部 N3 对照约1.070，第一次反序复测却为0.968。没有依据单次有利复测直接放行。

进一步使用独立父进程高频采样，子进程完成预热和 GC 后握手启动 parse，保留结果直至采样结束，再序列化。五轮交替采样中，基线/候选峰值中位数为 **129,466,368 / 129,024,000 bytes**，比率 **0.99658**；结束时 RSS 均约118.6 MB。请求间隔1 ms，实际观测最大间隔9.34 ms，不能称为精确1 ms采样。完整输出仍相同，证据见 `external-rss-1ms-01`。

高频结果支持此前50 ms采样漏掉不同阶段的峰值，而不是持续内存回退。本轮不宣称所有格式都有固定 RSS 降幅；此内存诊断的耗时也不用于速度结论。
