# PDF 原生内核阶段 12：全文风险与 run 统计

## 实现及边界

实现检查点为 DocVortex `a35a6f40d39240a8e6c81b38246a30161aa14fc1`，私有协议 17。MinerU 生产代码未改动，继续验证 `739ad39f` 对应的双仓组合。按用户要求单人执行，速度优先，RSS 门槛继续固定为最初 Rust 基线的 130%。

- 文档风险累积器在 Rust 内完成锚点筛选、相邻对、Y 簇、字体分组和跨页样式统计；逐行输入后仅返回提前命中或最终风险，保持原来的全文先后依赖。
- 完整 run 统计一次读取内部样本，在 Rust 内稳定排序锚点，计算相邻对、字距、bearing、中位数、强异常和同族传播。最终按原来的 run 键顺序构造统计对象，并保持成员对象身份。
- 线性插值分位数、首个并列簇/字体、重复来源行的集合与计数语义不变；独立的 Python 参考实现保留。非标准类型、越界或非有限输入明确选择参考路径，原生计算及输出构造异常直接传播。
- Rust 计算释放 GIL，不访问 PDFium，不新增线程池。中文函数说明、协议注册和 ABI 验证同步更新；wheel 矩阵加入完整字符几何测试。

这仍不是完整 Rust 文档几何内核：样本构造、样式修复、X/Y 修复和最终诊断的部分组织还在 Python；风险与 run 两个阶段仍有独立输入边界。全文布局、表格候选闭包、PDFium 文档所有权和矢量快照也尚未全部迁移。

## 选择依据

仅迁移风险筛查的首个候选保留在 `candidate-stage12`：三份热点的公开解析中位数总和仅下降 0.44%，属于波动级收益，未据此宣称稳定加速。

增加完整 run 统计后的 `candidate-stage12b`，相对上一版 `candidate-stage11` 的相同三样本试测总和下降 5.46%；demo1、中文论文2 分别下降 6.64%、8.59%，49.- 下降 0.55%。两版每份均预热一次、测量五次，完整输出相同。此小范围试测仅用于选方案，不能代替全量正式验收。

## 正式验收

本批以 DocVortex `3eef2d1` / MinerU `cabe6e34` 为基线，双方启用对应 Rust 实现。候选使用冻结的 `candidate-stage12b` / `mineru-stage8`，session 渲染参数不变；基线仍使用 legacy。冻结副本记录前序 HEAD 和 dirty 状态，实际源码摘要及扩展摘要写入每份报告，对应上述实现检查点。

每份文档预热一次、正式五次，逐文档交替版本；超过 5% 的退化反序复测，首次值保留在总和。内存独立采样同时刻进程树 RSS。构建、测试、模型录制和 profiler 不与正式计时混跑。

本批未重复完整冷启动与长期稳定性验收；上一批结果保留为协议 16 的历史证据，不能重标为协议 17 成绩。
