# 第七轮 Flash PDF 热点优化

第六轮冻结基线为 `843b599`，私有扩展协议 7。继续 `codex/rust-pdf-round6`
及 draft PR #14；本轮不合并或发布。

全部 17 份 demo／136 页的公开解析 Rust 中位耗时之和，目标比同期第六轮
降低至少 10%。完整覆盖 32 份 PDF／299 页及 186 个表格区域，不刷新历史金标；
任一文档持续超过 5% 的耗时或进程树 RSS 退化均不接受。

独立证据目录为 `output/pdf/rust-round7-20260926/`，包含基线源码、匹配的
协议 7 二进制、依赖清单、冻结区域输入及逐文件 SHA256／页数。
性能只在本机验证，CI 保留构建、ABI、安装及正确性测试。

## 阶段记录

| 阶段 | 内容 | 状态 |
|---|---|---|
| P0 | 基线源码、二进制、完整输入及依赖冻结 | 已完成 |
| P1 | 标题判定中栏带正文统计复用 | 双后端各 79 项针对性测试通过，三个重点 PDF 原生完整输出相等 |
| P2 | 普通字符源几何及只读字体准备，协议 8 | 238 项 Rust 针对性测试通过；32 PDF／299 页原生输出全部相等 |
| P3 | 保序映射组构建、有界文本投影与普通字体准备复用 | Rust 针对性 426 项通过；Python 357 项通过、69 项跳过；32 PDF／299 页原生输出相等 |

最终收益、差分、内存及安装平台证据将在全部源码完成后补充。

P1 定向剖析中，`中文论文2.pdf` 的正文 profile 实算次数从第六轮的 5,310
降至 450，行高调用从 1,028,145 降至 630,965。剖析时间不作为正式性能结果。
一次测量的阶段 pilot 仅用于发现方向和退化风险，不作为最终收益验收。

P2 保留协议 7 基线二进制。字体身份缓存只存活于单行准备后的只读处理，
最多 4,096 项；风险筛查和正式修复不共享缓存。Python 后端针对性验证
92 项通过、69 项原生专项跳过。Rust 检查及轮子 ABI 校验同步协议 8。

P3 保留混合样式页面的无样式物理行；只有整次普通字体检测均无样式且无
水平绘图线时才省去几何物化。独立差分曾发现逐行跳过会遗漏对齐证据，
该尝试已拒绝并补充回归测试。文本投影最多 256 块或 8,192 字符，超长块不缓存。
异常汉字映射及特殊字符继续使用完整去重参考路径。

逐字段验证的 Python 单遍映射路径在定向微测中退化，已撤下。最终融合入口
`mapping_glyph_rows` 直接借用现有普通字符列表，完成校验、映射保护与 Glyph
几何准备；字体等价及 Unicode 空白判定使用原 Python 语义。字典／字形解释、
异常汉字映射、复制及来源合并仍由 Python 参考路径承担，不重新启用旧的独立分组内核。
微测中 `caibao1`／`中文论文2` 的映射准备分别降低约 23%／20%，`demo2` 基本持平；
这些局部诊断不是公开解析的正式收益。

首次完整正式对比中，公开解析降低 6.31%，共享入口的混合元素、中文论文和
扫描样本未通过持续退化门槛；该轮保存在 `pre-fix-public`／`pre-fix-shared`，
不得作为最终验收。融合入口改为返回完整异字符保护组，由 Python 在全部准备
之后执行原 Unicode 转换，消除全页二次准备。空行仍保留参数真值回调和后端
加载异常，仅省去不会被消费的分类准备。三个文档的定向五次／反序复测通过，
最终完整验收使用修复后的同一源码与匹配二进制。
