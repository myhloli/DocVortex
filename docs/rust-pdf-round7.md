# 第七轮 Flash PDF 热点优化

第六轮冻结基线为 `843b599`，私有扩展协议 7。继续 `codex/rust-pdf-round6`
及 draft PR #14；本轮不合并或发布。

全部 17 份 demo／136 页的公开解析 Rust 中位耗时之和，目标比同期第六轮
降低至少 10%。完整覆盖 32 份 PDF／299 页及 186 个表格区域，不刷新历史金标；
任一文档持续超过 5% 的耗时或进程树 RSS 退化均不接受。

独立证据目录为 `output/pdf/rust-round7-20260926/`，包含基线源码、匹配的
协议 7 二进制、依赖清单、冻结区域输入及逐文件 SHA256／页数。
性能只在本机验证，CI 保留构建、ABI、安装及正确性测试。
