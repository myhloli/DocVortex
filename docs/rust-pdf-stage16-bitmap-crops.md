# PDF 原生内核阶段 16：独立位图与 Rust 直裁

## 实现边界

实现提交 `58e88519ba14c3d35de622958af21ec6e9d8d3a3`，私有协议 21 在实验性定向渲染会话中新增位图直裁路径。沿用 PDFium 的 DPI 200、长边 3500、相同渲染参数、OpenCV JPEG 编码器及默认参数；不改页面调度、并发预算或公开 Python 接口。

PDFium 渲染后只复制一次原始位图到不可变 Python 字节，随即关闭位图。纯 Rust 核心按行步长读取指定区域，连续完成通道转换与直角旋转；绑定借用不可变字节并释放 GIL，输出独立的连续 BGR 字节供 NumPy 只读视图及原编码器使用。PDFium 指针不进入像素算法，原位图及文档关闭后仍可处理缓冲。

该路径省去整页 PIL 解码、PIL 复制、整页 NumPy 复制和裁图后的 RGB/BGR 转换。它仍有原始位图的一次所有权复制和裁图输出物化，不能称为全链路零复制。RGB/BGR、四通道及灰度支持均保持参考路径的颜色语义；坐标归一化、取整、边缘裁剪及角度解释继续使用原逻辑。

无效视觉框继续按旧契约跳过；原生缓冲、步长、边界或计算错误明确传播，不静默切换后端。Python 参考后端及旧渲染器保留。整页输出、编码器、模型推理和导出 PDF 排版不在本次修改范围。
