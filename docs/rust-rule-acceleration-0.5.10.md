# DocVortex 0.5.10 原生 PDF 提速

0.5.10 保留正式 0.5.9 的完整解析输出，消除新增识别规则中的重复几何计算和 Python 对象处理成本。
公共 API 与 MinerU 调用方式保持兼容，内部 Python／Rust 扩展协议由 30 升至 31。

## 实现

- 复合路径在矩形展开前，每组只计算一次横纵基线，复杂度从最坏接近 O(n³) 降至 O(n²)。保持 `0.35 × em` 容差、75% 支持率及原边界比较；不同文字过滤阶段分别裁决最终图体。
- 批量处理数字噪声、遮挡候选、Form 内容流事件、字形位集及图片白边。Python 保留资源安全、矩阵传播和调用树判定，无法等价处理的输入完整回退。
- 批量处理坐标轴、公式几何、跨栏短尾、字体特征和表格局部证据。缓存绑定页面及当前输入状态，保留稳定索引、遍历顺序、平局规则与公式重放。
- macOS 整页渲染使用父进程预登记的共享内存交付原始像素，保持原渲染参数；图片解码后及时释放，错误、崩溃和取消回收整批资源。其他平台及分配失败保留原文件路径，不缓存渲染结果。
- 纯 Python 回退、PDFium 锁、GIL 和句柄生命周期保持原有约定。新增函数和内核附中文注释。

## 性能

同机测量 32 份 PDF／299 页（Flash 排除原有 OCR 样本，共 31 份）。三条链路串行执行三轮平衡配对，
每文档每版本预热一次、计时五次取中位数，版本顺序轮换。每轮总耗时为逐文档中位数之和；
下表跨轮取每文档三轮中位数的中位数后求和。RSS 在独立进程中采样完整进程树，包含渲染子进程。
shared 使用审计过的冻结模型输入，模型计算和输入审计不计入耗时。

| 链路 | 0.5.9 rust | 0.5.10 rust | 加速倍数 | 耗时降低 | 峰值 RSS 降低 |
| --- | ---: | ---: | ---: | ---: | ---: |
| DocVortex 公开 `parse()` | 28.20 s | 14.48 s | 1.95× | 48.65% | -0.17% |
| MinerU Flash | 28.05 s | 14.44 s | 1.94× | 48.53% | -0.30% |
| MinerU 共享 PDF 处理 | 19.19 s | 12.85 s | 1.49× | 33.06% | -0.15% |

加速倍数使用未舍入耗时计算；RSS 降幅为逐文档比率降幅的中位数，负数表示轻微增加。
三轮公开解析和 Flash 均不超过同机正式 0.5.8 耗时的 105%，相对 0.5.9 没有持续超过 5% 的逐文档耗时或 RSS 回退。
最慢柱图样本公开解析从约 9.1 秒降至约 0.30 秒。

## 输出与兼容验证

32 份基准、19 份／168 页维护语料及 187 份／208 页人工语料按 PDF SHA 去重，共 219 份／507 页。
19 份维护语料与基准重叠，人工语料与基准无 PDF SHA 重叠。Python、Rust、auto 的完整文字、样式、坐标、顺序和实际素材字节均与正式 0.5.9 一致；
额外复查图体、公式和图片裁切。已有裁切问题单独记录，不冒充本轮修复。

优化验收包括 Python 全量 8354 项通过、Rust 全量 9456 项通过，以及 Cargo tests、Clippy、格式检查、独立 wheel 安装和实 PDF 验证。
公开接口清单及类方法签名对照无变化；当前 MinerU 无需修改对接代码，既有 `docvortex>=0.5.4,<1` 约束包含 0.5.10。
构建后的 wheel 额外执行本轮新增的规则内核差分测试。

本地完整脚本、冻结源码、逐文档结果、失败试验、反序复测及输出证据保存在忽略目录
`output/pdf/rust-rule-acceleration-20261007/`，发布前接口审计与测试证据保存在
`output/pdf/release-0.5.10-20261007/`。格式化已确认完整 AST 不变，版本号调整不改变被测解析实现。
