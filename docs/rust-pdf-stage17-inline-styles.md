# PDF 原生内核阶段 17：快照样式证据

## 实现边界

私有协议 22 将 Flash 新鲜同源页面中的整段文字样式检测迁入 Rust。只提交行框、来源顺序、字符成员 ID 和绘图线，直接复用 `NativeTextSnapshot` 中的字符框、墨迹框、原始索引和字体。解释器 Unicode 属性、连字/控制字符归一化和字体正则按唯一值调用既有 Python 规则，纯 Rust 计算释放 GIL，最后物化 `PDFTextStyleLine`。

迁移包含字符稳定排序、可见字符/正文高度统计、粗体短片段与行首项目符号过滤、下划线/删除线匹配、墨迹穿越、分式横线排除、候选网格、稳定首目标选择和紧凑样式区间。保留完整候选覆盖和所有阈值，不包含算法改进。

公开可变字符入口仍走原检测器；内部只准入同源成员和普通几何。缺失成员身份、特殊对象或超出有界网格能力的坐标选择参考路径，不裁减候选；非法成员索引和原生计算错误明确传播。关闭 PDFium 文档后仍可消费快照。新增 `native_inline_style_batches` 诊断记录实际原生批次。

本批没有消除其他阶段仍需要的字符字典物化，也没有迁移链接判断、完整对象树或所有 Flash 规则。它不代表 P1/P2/P4 全部完成。
